# 🎮 Jogo da Forca no Terminal (CLI Hangman)

![NodeJS](https://img.shields.io/badge/node.js-6DA55F?style=for-the-badge&logo=node.js&logoColor=white)
![JavaScript](https://img.shields.io/badge/javascript-%23323330.svg?style=for-the-badge&logo=javascript&logoColor=%23F7DF1E)

Um projeto simples, clássico e interativo do **Jogo da Forca** desenvolvido inteiramente em **JavaScript (Node.js)**. O jogo é executado diretamente na linha de comando (Terminal) e testa seus conhecimentos adivinhando palavras do universo da programação.

---

## 🎯 Objetivo do Projeto
Este projeto foi criado com o intuito de praticar lógicas de programação com JavaScript, manipulação de arrays/strings e iteração com o usuário via terminal de forma assíncrona usando o módulo nativo `readline/promises` do Node.js.

## ✨ Funcionalidades
- **Seleção Aleatória:** O jogo sorteia uma palavra diferente a cada execução a partir de um banco de palavras focado em tecnologia (ex: *BACKEND, NODEJS, JAVASCRIPT, EXPRESS*).
- **Interface Interativa:** Leitura de entradas do usuário direto no terminal.
- **Sistema de Vidas:** O jogador possui 6 chances de errar antes de perder o jogo.
- **Feedback em Tempo Real:** Mostra o progresso das letras descobertas e avisa quando uma letra informada está incorreta.
- **Condições de Vitória/Derrota:** Validação automática de fim de jogo informando a palavra correta em caso de derrota.

---

## 🚀 Tecnologias Utilizadas
- **JavaScript (ES6+)**
- **Node.js** (Módulos nativos: `readline/promises` e `process`)
